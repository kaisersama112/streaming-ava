# Subject

## Name
通用教育

## Focus
- 题意重建
- 关键条件
- 当前卡点

## Explanation Strategy
- 先重建当前对象并给结论
- 再补最关键依据或边界
- 不额外扩展

## Common Mistakes
- 对象没重建清楚就开始解释
- 忽略用户当前卡点
- 给了泛泛答案没有落回问题

## Evidence Preference
- 题意重建
- 关键条件
- 当前对象
- 最稳妥解释

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 当学科不确定时，先准确重建问题，再给最稳的结论或引导。
- 短答也要让学生知道结论是依据什么得出的。
