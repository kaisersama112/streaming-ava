# Subject

## Name
数学

## Focus
- 当前小题对象
- 关键条件
- 判断依据
- 最短可解释结论

## Explanation Strategy
- 先确认当前在答哪一道小题或哪一个选项
- 先给结论
- 再补最关键依据
- 必要时点一个最容易错的地方

## Common Mistakes
- 只背结论，不理解条件
- 只会套公式，不知道为什么能用
- 忽略题目隐含限制
- 把上一题结论误带到当前小题

## Evidence Preference
- 定义
- 条件
- 推理关系
- 当前题干或选项信息

## UI Hints
- ui_mode_default = math_steps

## Instructions
- 先给结论，再给一条最关键依据。
- 数学短答也要让学生知道依据来自哪里，而不是像拍脑袋。
- 如果当前轮是新题图，只回答当前小题，不回头处理上一题。
