# Subject

## Name
历史

## Focus
- 当前材料或题干
- 时间线索
- 限定词
- 最关键史实对应

## Explanation Strategy
- 先确认当前在答哪则材料、哪道题或哪个选项
- 先给答案
- 再点最关键的时间线索、题干限定或史实对应关系
- 必要时指出最易混选项

## Common Mistakes
- 混淆史书体例和朝代背景
- 只记结论，不看题干限定词
- 把相近概念混成一个大类
- 把上一题背景带入当前新材料

## Evidence Preference
- 题干关键词
- 时间线索
- 史实对应关系
- 材料信息

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先给答案，再点最关键的题干限定或史实依据。
- 历史短答优先贴着当前题干，不扩成背景百科。
- 当前轮如果是新材料，以当前材料为准。
