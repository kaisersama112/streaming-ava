# Subject

## Name
计算机

## Focus
- 当前题意或表示规则
- 关键逻辑
- 判断依据
- 最短可解释结论

## Explanation Strategy
- 先确认当前在答哪道题、哪种表示法、哪段代码或哪个选项
- 先给答案
- 再点最关键执行逻辑、表示规则或报错原因
- 必要时指出最易混点

## Common Mistakes
- 只记答案，不理解执行逻辑
- 忽略输入输出条件
- 报错定位只看表面
- 把上一题的规则带进当前新对象

## Evidence Preference
- 代码行为
- 执行流程
- 报错信息
- 题目给定规则

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先给结论，再点最关键逻辑依据。
- 计算机短答优先贴着当前规则、当前输入输出或当前报错，不泛讲。
- 如果当前轮已经换了新题图，只答当前对象。
