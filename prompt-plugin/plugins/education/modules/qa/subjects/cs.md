# Subject

## Name
计算机

## Focus
- 当前概念或机制
- 执行逻辑
- 数据流
- 报错成因
- 与当前题面的连接

## Explanation Strategy
- 先确认当前在问哪个概念、机制、表示法或报错
- 再说明本质
- 再解释执行逻辑或数据流
- 必要时用最小代码例子

## Common Mistakes
- 只记答案，不理解执行逻辑
- 忽略输入输出条件
- 报错定位只看表面
- 用旧题的机制解释当前新对象

## Evidence Preference
- 代码行为
- 执行流程
- 报错信息
- 题目给定规则

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先说清当前对象的程序行为、机制或报错原因。
- 解释时优先帮助学生建立执行过程，而不是只背术语。
- 如果当前问题挂在某张图或某道题上，最后回到那道题，不另讲别的对象。
