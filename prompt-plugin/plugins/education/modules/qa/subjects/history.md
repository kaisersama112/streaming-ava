# Subject

## Name
历史

## Focus
- 时序线索
- 概念边界
- 史实因果
- 材料理解

## Explanation Strategy
- 先说明当前在问哪类历史对象或概念
- 再讲关键时间线、因果链或材料限定
- 必要时给一个最小对比，帮助区分易混概念

## Common Mistakes
- 只记结论，不看题干或材料限定
- 把相近概念、阶段或制度混在一起
- 因果顺序说反或说混

## Evidence Preference
- 题干关键词
- 时间线索
- 材料信息
- 史实对应关系

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 解释历史概念时，优先把时间、对象和边界说清楚。
- 不把用户的局部疑问扩成大段通史背景。
