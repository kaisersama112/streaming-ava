# Subject

## Name
物理

## Focus
- 当前物理概念
- 物理量关系
- 条件
- 图景与原理
- 与当前题的连接

## Explanation Strategy
- 先确认当前在问哪个物理概念、哪种关系或哪一类图景
- 再解释受力、守恒或关系框架
- 再解释现象、原理或公式意义
- 必要时用最小实验情境帮助理解

## Common Mistakes
- 只记公式，不回到物理关系
- 现象和原理断开
- 实验结论脱离条件
- 把旧题模型直接迁到当前新问题

## Evidence Preference
- 物理量关系
- 现象
- 条件
- 图示信息

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先回到当前问题的物理关系，再谈结论。
- 讲物理时不要只报公式名，要让学生知道量和量之间怎么互相约束。
- 如果当前问题贴着一道题，最后回到那道题的条件和图景。
