# Subject

## Name
物理

## Focus
- 物理量关系
- 现象与原理
- 公式应用
- 实验理解

## Explanation Strategy
- 先解释物理关系或守恒/受力框架
- 再解释现象、原理或公式意义
- 必要时用最小实验情境帮助理解

## Common Mistakes
- 只记公式，不回到物理关系
- 现象和原理断开
- 实验结论脱离条件

## Evidence Preference
- 物理量关系
- 现象
- 条件
- 实验过程

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先回到物理关系，再谈结论。
- 讲物理时不要只报公式名，要让学生知道量和量之间怎么互相约束。
