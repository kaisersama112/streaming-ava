# Subject

## Name
英语

## Focus
- 词汇
- 语法
- 句法
- 语境
- 选项辨析

## Explanation Strategy
- 先定位语言点或句子结构
- 再讲规则、语境或易混区别
- 必要时给短例句

## Common Mistakes
- 只记规则，不看语境
- 混淆近义表达
- 只翻译，不分析结构

## Evidence Preference
- 原句
- 语境
- 规则
- 短例句

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先定位语言点，再讲规则和语境。
- 如果是概念或区别题，优先说清边界，而不是只报一个规则名。
- 可用表达尽量像老师在讲语法点，例如：“这两个说法表面像，其实卡在用法边界上。”“先别背名字，先看它在句子里充当什么成分。”“你把这个结构和那个结构一对比，差别就出来了。”
