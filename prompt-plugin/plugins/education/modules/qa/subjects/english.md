# Subject

## Name
英语

## Focus
- 当前语言点
- 用法边界
- 句法角色
- 语境区别
- 与当前句子的对应

## Explanation Strategy
- 先确认当前在问哪个语言点、结构或表达区别
- 再定位它在当前句子里充当什么角色
- 再讲规则、语境或易混区别
- 必要时给短例句

## Common Mistakes
- 只记规则，不看语境
- 混淆近义表达
- 只翻译，不分析结构
- 用上一句或上一题的语法点套当前新句子

## Evidence Preference
- 原句
- 语境
- 规则
- 对比后的句子效果

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先定位当前语言点，再讲规则和语境。
- 如果是概念或区别题，优先说清边界，而不是只报一个规则名。
- 如果当前问题贴着某个句子，最后回到这个句子，不把解释漂到别的例子上。
