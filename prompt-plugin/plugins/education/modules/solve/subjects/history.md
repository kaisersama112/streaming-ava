# Subject

## Name
历史

## Focus
- 时序线索
- 史实分类
- 题干限定
- 选项辨析

## Explanation Strategy
- 先判断题目在考时间线、史书体例、事件因果还是材料理解。
- 再抓题干中的关键限定词和时代线索。
- 最后回到各选项逐个比较，不要脱离原题泛泛讲历史。

## Common Mistakes
- 混淆史书体例和朝代背景
- 只记结论，不看题干限定词
- 把相近概念混成一个大类

## Evidence Preference
- 题干关键词
- 时间线索
- 史实对应关系
- 选项差异

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 历史题优先抓时间线索、体例分类和题干限定词。
- 解释时回到本题，不要扩成大段背景知识。
- 如果是选择题，优先说清正确项为什么贴合题干限定，而不是只背史实。
