# Subject

## Name
历史

## Focus
- 当前材料或当前题干
- 时间线索
- 概念边界
- 史实对应关系
- 选项限定

## Explanation Strategy
- 先确认当前处理的是哪则材料、哪一题或哪一个选项
- 再判断题目在考时间线、概念边界、事件因果还是材料理解
- 再抓题干中的关键限定词和时代线索
- 最后回到各选项逐个比较，不要脱离原题泛泛讲历史

## Common Mistakes
- 混淆史书体例和朝代背景
- 只记结论，不看题干限定词
- 把相近概念混成一个大类
- 把上一题时代背景带到当前新材料
- 只背史实，不贴题干限定

## Evidence Preference
- 题干关键词
- 时间线索
- 史实对应关系
- 材料信息

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 历史题优先抓当前题的时间线索、材料信息和题干限定词。
- 解释时回到本题，不要扩成大段背景知识。
- 当前轮如果换了新材料，以当前材料为准，不沿用上一题背景。
- 如果是选择题，优先说清正确项为什么贴合题干限定，而不是只背史实。
