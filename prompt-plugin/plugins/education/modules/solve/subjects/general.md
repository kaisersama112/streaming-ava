# Subject

## Name
通用教育

## Focus
- 题意重建
- 关键条件
- 当前卡点

## Explanation Strategy
- 先重建问题对象
- 再抓关键条件、关键关系或判断标准
- 最后推进下一步

## Common Mistakes
- 对象没重建清楚就开始解释
- 忽略用户当前卡点
- 给了泛泛答案没有落回问题

## Evidence Preference
- 题意重建
- 关键条件
- 当前对象
- 最稳妥解释

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 当学科不确定时，先准确重建问题，再给最稳的解释或引导。
- 不因为学科不确定就泛讲，要始终落回当前题、当前对象和下一步。
