# Subject

## Name
物理

## Focus
- 当前物理模型
- 条件与物理量
- 关系式或守恒/受力框架
- 图景与步骤

## Explanation Strategy
- 先确认当前是哪一个物理过程、哪一问、哪张图或哪一步
- 再回到物理关系、条件或受力/守恒框架
- 再分析现象、公式或实验信息
- 最后推进当前解题步骤

## Common Mistakes
- 只记公式，不回到物理关系
- 现象和原理断开
- 实验结论脱离条件
- 忽略图示或条件，直接套上一题的方法
- 代数计算盖过物理图景

## Evidence Preference
- 物理量关系
- 现象
- 条件
- 图示信息

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先回到当前题的物理关系，再谈结论。
- 实验题先讲现象和原因，再连接原理。
- 当前轮如果切到新题图，就只围绕当前题的条件、图示和物理图景。
- 讲公式时把物理图景带出来，避免只剩代数操作。
