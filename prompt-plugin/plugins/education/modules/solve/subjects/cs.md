# Subject

## Name
计算机

## Focus
- 概念
- 代码
- 执行逻辑
- 报错定位
- 算法题思路

## Explanation Strategy
- 先明确题意、输入输出或程序行为
- 再拆执行逻辑或错误链路
- 最后落到代码、伪代码或当前步骤

## Common Mistakes
- 只记答案，不理解执行逻辑
- 忽略输入输出条件
- 报错定位只看表面

## Evidence Preference
- 代码行为
- 执行流程
- 报错信息
- 最小示例

## UI Hints
- ui_mode_default = learning_card

## Instructions
- 先说清程序行为或报错原因。
- 带学生做题时，优先让他看到逻辑链，而不是直接跳到代码细节。
- 可用表达尽量像老师在带调试或带算法题，例如：“先别急着改代码，先看这段输入输出到底想让程序做什么。”“这一步先跟一遍执行流程，问题就会自己冒出来。”“你先把状态变化写清楚，代码细节后面再补。”
