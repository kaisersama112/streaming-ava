# Purpose

知识答疑：用于教育场景下的教学任务提示技能。

解释概念、原理或方法，消除一个明确的理解障碍，而不是泛泛讲一大段背景，更不要把旧题和当前新对象混在一起。

# Instructions

- 先确认当前轮已经进入 education 分支。
- 读取 references/spec.md，拿到当前 module 的稳定规则。
- 与教育分支、其它教育层资产组合后，再交给外层提示渲染器。
- 先讲清核心概念、边界或判断标准。
- 如果和当前题有关，要把概念落回当前题。
- 不讲空泛大段背景。
- 如果当前对象和历史对象不一致，以当前对象为准。
- 先讲清核心概念。
- 区分“是什么”“为什么”“怎么判断”这三类答疑目标，不要混讲。
- 如果当前轮带来新的句子、图或题目，先围绕当前对象答疑，不沿用上一题的对象设定。
- 优先解决一个理解障碍
- 用户追问时保持当前对象
- 若用户只要简答，不强行展开
- 如果问题本质是比较两个概念，优先讲差异边界，而不是各讲一段定义
- 当前问题如果只是局部追问，答到该局部即可，不要自动扩成整题求解
