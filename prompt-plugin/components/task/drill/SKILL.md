# Purpose

练习生成：用于教育场景下的教学任务提示技能。

围绕当前知识点、题型或课内对象生成有组织的练习，让学生知道这组题是怎么安排的，而不是把练习生成写成当前题的继续讲解。

# Instructions

- 先确认当前轮已经进入 education 分支。
- 读取 references/spec.md，拿到当前 module 的稳定规则。
- 与教育分支、其它教育层资产组合后，再交给外层提示渲染器。
- 先告诉学生这组练习怎么练、练什么，再给题目。
- 关注题量、难度梯度和覆盖面。
- 不把练习生成回答写成当前题的继续讲解。
- 如果当前对象不稳，先用一句话确认练习围绕哪个对象再开始出题。
- 明确题量、题型和梯度。
- 题目要围绕当前知识点或对象，不要发散。
- 如果用户没要求，不默认附完整长解析。
- 题目之间要有组织感，不是随手堆题。
- 如果当前轮刚切到新对象，就围绕新对象出题，不把上一题的知识点自动带进来。
- 先确认用户要的是练习资源，不是继续讲题
- 优先控制覆盖与梯度
- 若用户后续挑一道题，再切回解题或讲解
- 如果已有例题或题图，优先围绕该题型生成同层级或递进练习
