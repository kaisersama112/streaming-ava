# Purpose

计算机：用于教育场景下的学科解释策略提示技能。

该知识 Skill 关注以下内容：

当前题意

输入输出或表示规则

执行逻辑

关键状态变化

报错或概念边界

# Instructions

- 先确认当前轮已经进入 education 分支。
- 读取 references/spec.md，拿到当前 subject 的稳定规则。
- 与教育分支、其它教育层资产组合后，再交给外层提示渲染器。
- 先说清当前题的规则、程序行为或报错原因。
- 带学生做题时，优先让他看到逻辑链，而不是直接跳到代码细节。
- 当前轮如果换了新截图、新表示题或新代码段，就只围绕当前对象分析。
- 先把状态变化、位表示或执行流程说清楚，代码细节后补。
- 先确认当前处理的是哪道题、哪段代码、哪种表示法或哪一条报错
- 再明确题意、输入输出或规则前提
- 再拆执行逻辑、状态变化或错误链路
- 最后落到代码、伪代码或当前步骤
- 代码行为
- 执行流程
- 报错信息
- 题目给定的表示规则或格式要求
