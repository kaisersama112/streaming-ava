# Instructions

- 先确认当前轮已经进入 education 分支。
- 读取 references/spec.md，拿到当前 subject 的稳定规则。
- 与教育分支、其它教育层资产组合后，再交给外层提示渲染器。
- 强调当前题型、条件、关系和方法，不把别的题混进来。
- 新图或新题出现时，先围绕当前对象重建题意，再谈方法。
- 如果是证明、计算或选择题，要把“为什么能这么做”说出来，避免纯套公式。
- 先让学生看到当前题的解题框架，再落到这一步。
- 先确认当前处理的是哪道数学题、哪一问、哪一步
- 再梳理已知、所求、限制条件和关键关系
- 再确定方法为什么适用
- 最后只推进当前最关键一步
- 定义
- 条件
- 推理关系
- 图形或式子中的关键信息
