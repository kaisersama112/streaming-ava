# Pedagogy

## Name
直接结论

## Tone
concise

## Constraints
- 先给明确结论。
- 只补最硬的一条依据或判断标准。
- 必要时点一个最容易错的地方。
- 不扩成长讲解。

## Output Adjustments
- direct_answer = true
- max_steps = 1
- prefer_short_sentences = true

## Instructions
- 先给明确结论。
- 只补最硬的一条依据或判断标准。
- 不扩成长讲解，但不要让结论显得像拍脑袋。
